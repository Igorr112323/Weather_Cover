# WeatherCover

Современное перерисованное приложение погоды: быстрый интерфейс, плавные анимации, почасовой прогноз, карта и офлайн-режим.

## Что внутри

- **Живой почасовой прогноз**: график температуры + 24 часа с иконками и вероятностью осадков.
- **7 дней**: дневные минимумы/максимумы, режим осадков и ветра.
- **Карта**: Leaflet + OpenStreetMap с плавной анимацией маркера и круга вокруг точки.
- **Анимации погоды**: дождь, снег, грозы, туман, облака — всё на лёгком canvas, без лагов.
- **Поиск городов**: геокодинг Open-Meteo + быстрое офлайн-резервирование.
- **Своё местоположение** по геолокации.
- **Офлайн-режим**: если интернет недоступен, либо если API не ответил, приложение генерирует правдоподобную погоду для выбранной точки.

## Запуск в разработке

```bash
npm install
npm run dev
```

Откройте `http://localhost:5173`.

## Сборка веб-версии

```bash
npm run build
```

## Версия для Windows (EXE)

Windows-сборка собирается в GitHub Actions. После завершения сборки EXE доступен из артефакта:

- Ветка: `arena/01a0852e-weather-cover`
- Откройте вкладку **Actions** в репозитории и скачайте артефакт `WeatherCover-win32-x64`.

Внутри архива лежит папка `WeatherCover-win32-x64` с файлом **`WeatherCover.exe`**.

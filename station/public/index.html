Зачем нужен проверочный EXE

Приложение хранит лицензию в профиле (%APPDATA%\AgroPrognoz\agroprognoz.license), и файл один на все копии программы. Поэтому свежий EXE на активированном компьютере код не спросит. Проверочная копия называется AgroPrognoz-check-<id>.exe и хранит лицензию в своём файле — она обязана запросить код. Это тот же самый EXE: меняются только имя файла и место хранения лицензии.

Проверка механизма активации

Полный сценарий (чистый компьютер → код принят → перезапуск → чужая машина → подмена файла → сброс → отзыв → подделка) прогоняется в проекте приложения командой: 

npm run activation:selftest

А код этого компьютера, который просят в заявке:

npm run license:machine

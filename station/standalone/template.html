Активация ключей

Работает офлайн прямо в браузере: закрытый ключ никуда не отправляется, подписывает код этот файл. Лицензии бессрочные — поля «действует до» не существует.

Здесь появится код, сообщение покупателю и файл .agrolic. Нужен закрытый ключ — вкладка «Ключи».

EXE, который запрашивает код активации

  1. Скачай установочный файл (это официальный portable EXE, установка не нужна):
    Скачать AgroPrognoz-portable.exe
  2. Если ты запускаешь EXE на компьютере, где активация уже была — файл лицензии один на все копии программы, поэтому код он не спросит. Чтобы увидеть экран ввода кода, выполни в cmd: 
    move "%APPDATA%\AgroPrognoz\agroprognoz.license" "%APPDATA%\AgroPrognoz\agroprognoz.license.bak"
    Вернуть как было: move обратно (переименовать .bak в agroprognoz.license).
  3. Проверочный режим (каждая новая копия спрашивает код, твоя активация не трогается) работает в сборках, где есть electron/license/checkmode.cjs. Собери такую копию сам или переименуй EXE: 
    copy release\AgroPrognoz-0.2.1-portable.exe release\AgroPrognoz-check-demo.exe
release\AgroPrognoz-check-demo.exe     :: спросит код

Проверить код активации

Проверка идёт тем же алгоритмом, что и в приложении: подпись Ed25519, продукт, список отзыва, отпечаток компьютера. Дат станция не читает — лицензия бессрочная.

Результат проверки.
Журнал хранится в этом браузере (localStorage) — это учёт выдачи. Чтобы он попадал в общий secrets/ledger.csv проекта, используй студию/станцию: npm run license:studio или npm run station.

Закрытый ключ (для выдачи кодов)

Вставь содержимое secrets/license-key.json из проекта приложения — или одну строку base64 из поля privateKey. Ключ останется в этом браузере (localStorage) и никуда не уйдёт: страница работает без сервера и без интернета. Секретные каталоги в git не попадают.

Открытый ключ приложения

Открытый ключ лежит в самом приложении (electron/license/keys.cjs) — по нему станция сверяет, что код будет принят. Отзывы (серийники) тоже здесь.
